# SDK exchange oracle

This small Poplar program emits four consecutive tile-to-tile copies into one
receiver. It is an external oracle for the supervisor rows generated by the
official SDK; it is not part of ipu-stack code generation.

Build and extract an executable after enabling the SDK environment:

```sh
source "$POPLAR_SDK_ENABLED/enable.sh"
g++ -std=c++17 -O2 phase.cpp -o /tmp/sdk-exchange-oracle \
  -I"$POPLAR_SDK_ENABLED/include" -L"$POPLAR_SDK_ENABLED/lib" -lpoplar
/tmp/sdk-exchange-oracle /tmp/sdk-exchange.poplar_exec 52 0
../../../ipu-exchange-re/tools/extract_gc_exe.sh \
  /tmp/sdk-exchange.poplar_exec /tmp/sdk-exchange
```

The source tensors are mapped to logical tiles 5 through 8 and the destination
tile is the final command-line argument. The `KeepSeparated` vertex prevents
the four destination tensors from being folded into one allocation, making
the receiver's consecutive PIC/XPIC cutovers visible in its ELF row.

`decode.py` uses the SDK's own IPU21 disassembler for individual hexadecimal
words. Run it with the Python interpreter from the enabled SDK environment.

The recovered instruction semantics and the corresponding ipu-stack decoder
are documented in `docs/EXCHANGE_INSTRUCTION_REFERENCE.md`.
